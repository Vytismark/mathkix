======================================================================================================================================
USA MATH CURRICULUM STANDARDS BY GRADE LEVEL - REFERENCE TABLE
Common Core State Standards for Mathematics (CCSSM)
======================================================================================================================================

Purpose: Structured math curriculum standards for each USA grade level (K–4),
designed to power a learning app. Follows CCSSM. Each grade includes critical
areas, learning expectations, content overview, and detailed standards by domain.

Grades covered: Kindergarten, Grade 1, Grade 2, Grade 3, Grade 4
Additional grades will be added as they are developed.

KINDERGARTEN
======================================================================================================================================

--------------------------------------------------------------------------------------------------------------------------------------
CRITICAL AREAS
--------------------------------------------------------------------------------------------------------------------------------------

+-----+------------------------------------------+-----------------------------------------------------------------------------------------+
| #   | Critical Area                            | Description                                                                             |
+-----+------------------------------------------+-----------------------------------------------------------------------------------------+
| 1   | Number and Operations                    | Students use numbers, including written numerals, to represent quantities and solve     |
|     |                                          | quantitative problems: counting objects in a set, counting out a given number of        |
|     |                                          |   objects,                                                                              |
|     |                                          | comparing sets or numerals, and modeling simple joining/separating situations with sets |
|     |                                          | of objects or equations (e.g., 5 + 2 = 7 and 7 - 2 = 5).                                |
|     |                                          | Students choose, combine, and apply effective strategies:                               |
|     |                                          |   - Quickly recognizing the cardinalities of small sets of objects.                     |
|     |                                          |   - Counting and producing sets of given sizes.                                         |
|     |                                          |   - Counting the number of objects in combined sets.                                    |
|     |                                          |   - Counting the number of objects that remain after some are taken away.               |
|     |                                          | Note: Students should see addition and subtraction equations; writing equations         |
|     |                                          | is encouraged but not required.                                                         |
+-----+------------------------------------------+-----------------------------------------------------------------------------------------+
| 2   | Geometry                                 | Students describe their physical world using geometric ideas (shape, orientation,       |
|     |                                          | spatial relations) and vocabulary. They identify, name, and describe 2-D shapes         |
|     |                                          | (squares, triangles, circles, rectangles, hexagons) and 3-D shapes (cubes, cones,       |
|     |                                          | cylinders, spheres). They use basic shapes and spatial reasoning to model objects       |
|     |                                          | and construct more complex shapes.                                                      |
|     |                                          | Note: More learning time in Kindergarten should be devoted to number than other topics. |
+-----+------------------------------------------+-----------------------------------------------------------------------------------------+

Note: Detailed Standards (domain/cluster/code level) are not listed for Kindergarten
      in the CCSSM source. Standards are embedded in the critical area descriptions above.

GRADE 1

--------------------------------------------------------------------------------------------------------------------------------------
CRITICAL AREAS
--------------------------------------------------------------------------------------------------------------------------------------

+-----+-------------------------------------+----------------------------------------------------------------------------------------------+
| #   | Critical Area                       | Description                                                                                  |
+-----+-------------------------------------+----------------------------------------------------------------------------------------------+
| 1   | Addition and Subtraction            | Students develop strategies for adding and subtracting whole numbers using models            |
|     |                                     | (discrete objects, length-based models) for add-to, take-from, put-together, take-apart,     |
|     |                                     | and compare situations. They understand connections between counting and                     |
|     |                                     | addition/subtraction. They use properties of addition (e.g., "making tens") and compare      |
|     |                                     | a variety of solution strategies to build understanding of the relationship between          |
|     |                                     | addition and subtraction. Goal: fluency within 20; solve problems within 100.                |
+-----+-------------------------------------+----------------------------------------------------------------------------------------------+
| 2   | Place Value                         | Students develop efficient, accurate, and generalizable methods to add within 100 and        |
|     |                                     | subtract multiples of 10. They compare whole numbers (at least to 100) to develop            |
|     |                                     | understanding of relative sizes. They think of whole numbers 10–100 in terms of tens         |
|     |                                     | and ones (recognizing 11–19 as a ten and some ones). Through number sense activities         |
|     |                                     | they understand the order of counting numbers and their relative magnitudes.                 |
+-----+-------------------------------------+----------------------------------------------------------------------------------------------+
| 3   | Measurement                         | Students develop understanding of the meaning and processes of measurement, including        |
|     |                                     | iterating (building up the length of an object with equal-sized units) and the               |
|     |                                     | transitivity principle for indirect measurement.                                             |
+-----+-------------------------------------+----------------------------------------------------------------------------------------------+
| 4   | Geometry                            | Students compose and decompose plane or solid figures (e.g., two triangles → quadrilateral)  |
|     |                                     | building understanding of part-whole relationships and properties of original and            |
|     |                                     | composite shapes. They recognize shapes from different perspectives and orientations,        |
|     |                                     | describe geometric attributes, and determine similarities and differences - laying           |
|     |                                     | background for congruence and symmetry.                                                      |
+-----+-------------------------------------+----------------------------------------------------------------------------------------------+

| #   | Critical Area                       | Description                                                                                  |
+-----+-------------------------------------+----------------------------------------------------------------------------------------------+
| 1   | Multiplication and Division         | Students develop an understanding of the meanings of multiplication and division through     |
|     |                                     | equal-sized groups, arrays, and area models. Multiplication is finding an unknown product;   |
|     |                                     | division is finding an unknown factor. For equal-sized group situations, division can        |
|     |                                     | require finding the unknown number of groups or the unknown group size. Students use         |
|     |                                     | properties of operations to calculate products of whole numbers, using increasingly          |
|     |                                     | sophisticated strategies based on these properties. By comparing solution strategies,        |
|     |                                     | students learn the relationship between multiplication and division.                         |
+-----+-------------------------------------+----------------------------------------------------------------------------------------------+
| 2   | Fractions                           | Students develop an understanding of fractions, beginning with unit fractions. They view     |
|     |                                     | fractions as built out of unit fractions and use visual fraction models to represent parts   |
|     |                                     | of a whole. Students understand that the size of a fractional part is relative to the        |
|     |                                     | whole (e.g., 1/2 of a small bucket may be less than 1/3 of a large bucket; 1/3 of a          |
|     |                                     | ribbon is longer than 1/5 of the same ribbon). Students use fractions to represent           |
|     |                                     | numbers equal to, less than, and greater than one. They compare fractions using visual       |
|     |                                     | models and strategies based on equal numerators or denominators.                             |
+-----+-------------------------------------+----------------------------------------------------------------------------------------------+
| 3   | Area                                | Students recognize area as an attribute of two-dimensional regions. They measure area        |
|     |                                     | by finding the total number of same-size unit squares required to cover the shape without    |
|     |                                     | gaps or overlaps. Students understand that rectangular arrays can be decomposed into         |
|     |                                     | identical rows or columns. By decomposing rectangles into rectangular arrays of squares,     |
|     |                                     | students connect area to multiplication, and justify using multiplication to determine       |
|     |                                     | the area of a rectangle.                                                                     |
+-----+-------------------------------------+----------------------------------------------------------------------------------------------+
| 4   | Geometry                            | Students describe, analyze, and compare properties of two-dimensional shapes. They           |
|     |                                     | compare and classify shapes by their sides and angles, connecting these with definitions     |
|     |                                     | of shapes. Students also relate their fraction work to geometry by expressing the area       |
|     |                                     | of part of a shape as a unit fraction of the whole.                                          |
