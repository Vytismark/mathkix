================================================================================
APP IDEA - MATH LEARNING APP FOR KIDS
================================================================================

OVERVIEW
--------
A math-focused app for kids built on scientifically proven educational methods.
Features dynamic difficulty adjustment (rule-based + AI via Anthropic), an AI
level finder using free diagnostic questions, and support for multi-step answer
input.

================================================================================
STAGE 1 MVP
================================================================================

1. BRAND NAME

2. DOMAIN PURCHASE
   - Secure domain for the web app

3. CONTENT
   - High-quality math content for Kindergarten through Grade 5
   - Aligned with CCSSM standards

4. WEB APP (Core Build)
   - AI-powered level finder quiz
